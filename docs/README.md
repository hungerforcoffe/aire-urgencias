# `docs/` — la documentación del proyecto

| Carpeta | Qué hay | Para quién |
|---|---|---|
| [`informe/`](informe/) | **El informe final**: qué se hizo, qué se encontró y qué no se puede afirmar | quien quiere el resultado |
| [`calidad/`](calidad/) | Cada decisión de limpieza de datos, con su umbral, su justificación y lo que se pierde | quien quiere auditar un número |
| [`reconocimiento/`](reconocimiento/) | Cómo es realmente cada fuente antes de escribir código: formatos, esquemas y trampas | quien va a trabajar con estas fuentes |
| [`nube/`](nube/) | Operación del bucket S3 y de los permisos del equipo | quien va a operar la base |

Si solo vas a leer un documento, que sea
[`informe/INFORME.md`](informe/INFORME.md).
